# Portfolio Website

Welcome to my portfolio website repository! This project showcases my skills, projects, and experience as a developer. It is designed to provide a dynamic and responsive user experience, highlighting my work and allowing visitors to connect with me.

## Overview

This portfolio website is a personal project aimed at presenting my professional profile, including my skills, education, and projects. It is fully responsive and optimized for various screen sizes, ensuring a seamless experience for all users.

## Features

- **About Me Section**: A brief introduction about myself.
- **Education Section**: Details about my academic background.
- **Skills Section**: A grid showcasing my technical skills with icons.
- **Projects Section**: A collection of my projects with descriptions and links to their repositories.
- **Contact Section**: Links to my social media profiles and email for easy communication.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Interactive Popups**: Project details are displayed in a popup window for better user experience.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout, including responsive design with media queries.
- **JavaScript**: For interactivity and dynamic content rendering.
